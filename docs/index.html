Mental Health App API (2.0.0)

Download OpenAPI specification:

API for the Mental Health student wellbeing platform: events, doctors, appointments and user accounts. The partner-facing part is the Events API.

Versions. /api/v2/events is current and returns lists as { data, count }. /api/v1/events (also served at /api/events) still works and returns the old bare array, but it is deprecated and stops working on 20 November 2026. Every v1 response carries Deprecation, Sunset and Link: rel="successor-version" headers. To migrate, read response.data instead of the root array.

Auth. Partners send an X-API-Key header on event reads. The website uses a login session cookie instead. If the server has no keys configured, the key check is off.

Partner

Data we consume from StrathShop (Group 8)

Counseling services from StrathShop (Group 8)

Our server calls StrathShop (v2 by default) with a 1.5 s timeout and 2 retries. If the partner fails it returns the last good data with stale: true. If nothing is saved yet it returns 502. This route needs no key or login.

Responses

  • 502
