Mental Health App - Events API (1.0.0)

Download OpenAPI specification:

This is the Events API that Group 10 (RideCompare) will use. It lets them read our event list so they can suggest ride destinations. Reading events (GET) is public. Creating, updating and deleting events requires an admin session (log in via POST /api/auth/login first).

Get a list of upcoming events

Group 10 needs this to show events as ride destinations. Can filter by date using "after".

query Parameters
after
string <date>
Example: after=2026-08-31

Only show events on or after this date (format like 2026-08-31)
